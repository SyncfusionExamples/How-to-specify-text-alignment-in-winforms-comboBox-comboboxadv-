# How-to-specify-text-alignment-in-winforms-comboBox-comboboxadv-
This example demonstrates how to align text within the Syncfusion WinForms ComboBoxAdv control. ComboBoxAdv is an enhanced version of the standard ComboBox control, offering additional styling and layout capabilities. One of its useful features is the ability to control the alignment of the text displayed within the combo box.

Text alignment can be customized using the TextAlign property, which allows developers to set the horizontal alignment of the text to Left, Center, or Right. This is particularly helpful when designing user interfaces that require consistent formatting or when aligning text with other UI elements.

## Example
To center-align the text in a ComboBoxAdv control, you can use the following C# code:
```csharp
// To specify TextAlignment
Mytextbox.TextAlign = HorizontalAlignment.Center;

This simple property setting ensures that the text inside the ComboBoxAdv is visually centered, improving the overall appearance of the form.
